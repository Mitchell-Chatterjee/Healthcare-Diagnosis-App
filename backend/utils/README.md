# Backend Utils - Healthcare Diagnosis App

This directory contains utility scripts, demos, and development tools for the healthcare diagnosis backend.

## 📁 Contents

- `simple_healthcare_workflow_demo.py` - Simple demo showing the healthcare workflow
- `dev_tools.py` - Development utilities and helpers
- `data_generation.py` - Tools for generating test data
- `performance_benchmarks.py` - Performance testing utilities

## 🛠️ Development Tools

Run scripts from the backend root directory:

```bash
# Run the simple demo
python -m utils.simple_healthcare_workflow_demo

# Generate test data
python -m utils.data_generation

# Run performance benchmarks  
python -m utils.performance_benchmarks
```
